✨ Características del Sistema

🔗 RPC Distribuido

Comunicación entre módulos mediante XML-RPC sobre HTTP.

📄 Formato JSON

Todas las respuestas en formato JSON para fácil integración.

🌐 Multi-Computadora

Cada módulo puede ejecutarse en máquinas diferentes.

📝 Documentado

Código completamente documentado línea por línea.

🛡️ Tolerante a Fallos

Maneja desconexiones y errores de red gracefully.

🔍 Auditable

Funciones de consulta para reportes y auditorías.

🚀 Cómo Usar el Sistema

1. Iniciar Servidores

# Servidor Compras/Ventas (Puerto 9000)
python artefacto_compras_ventas.py

# Servidor Contabilidad (Puerto 8000)
python artefacto_contabilidad.py

2. Ejecutar Clientes

# Cliente Atención Proveedores
python cliente_atencion_proveedores.py

# Cliente Tienda
python cliente_tienda.py

3. Configurar IPs

# En cada cliente, configurar IP del servidor:
IP_COMPRAS_VENTAS = "192.168.1.10"  # IP donde corre Compras/Ventas
PUERTO_COMPRAS_VENTAS = 9000

🔧 Configuración de Red

Firewall de Windows

Abrir puertos 9000 y 8000 en el Firewall para permitir conexiones RPC.


Pasos:

  1. Panel de Control → Firewall de Windows
  2. Configuración avanzada → Reglas de entrada
  3. Nueva regla → Puerto TCP 9000 y 8000
  4. Permitir conexión → Perfil privado
